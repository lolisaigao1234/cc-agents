# Guard: block remote branch deletion, reflog expiry, find -delete and rsync --delete

## Parent

#3

## What to build

The guard is the hard block on commands that destroy work or history. Some commands like that still get through it. None of them was covered by the old guard outside the loop's own state, so this is not a regression; it was found in the spec review of #4.

- `git push --delete origin <branch>`, `git push origin :<branch>`, `git push --mirror`
- `git reflog expire --expire=now …`, `git gc --prune=now`
- `find … -delete`
- `rsync … --delete`

## Acceptance criteria

- [ ] The guard denies each command above, and spellings of them that differ only in flag order or git global options
- [ ] Text that only mentions them, such as a search pattern or commit message, is still allowed
- [ ] Each case is in the table-driven guard test
