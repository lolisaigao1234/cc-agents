## What to build

The decisions from #3 become the repository's authoritative docs, and the docs they supersede leave the model's reach.

- Four ADRs: 0005 reuse Matt Pocock's skills and native Claude Code, with the plugin as guardrails and visibility only (supersedes 0001–0004); 0006 Trace; 0007 Doc authority; 0008 the human-only Archive.
- The glossary moves to `GLOSSARY.md`, the file Matt's 1.3.1 skills read. It keeps only the terms that survive the debloat, and the domain-docs config points at it.
- The superseded docs (ADRs 0001–0004, the two research notes, the old glossary, the quality-loop README) move into `archive/`, mirroring their original paths. Each gets a one-line "Superseded by ADR-0005" header before it moves.
- This repository's project settings deny `Read` under `archive/`, so the archive is protected natively before any plugin code exists.
