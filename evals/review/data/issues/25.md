# typecheck:mod fails: the mod's tsconfig extends a types folder that isn't in the repo

## Problem

`npm run typecheck:mod` (and so `npm run check`) fails on a clean checkout of `main` (5a1d1c5):

```
error TS5083: Cannot read file '…/plugins/trace/.claude-plugin/types/tsconfig.json'.
plugins/trace/hooks/band.tsx(5,36): error TS2307: Cannot find module 'claude-code' …
plugins/trace/hooks/band.tsx(162,9): error TS17004: Cannot use JSX unless the '--jsx' flag is provided.
plugins/trace/test/band.test.tsx(1,36): error TS2307: Cannot find module 'claude-code/testing' …
plugins/trace/types/index.d.ts(29,22): error TS2304: Cannot find name 'Shaped'.
```

18 errors in all, from one cause: `plugins/trace/tsconfig.json` extends `./.claude-plugin/types/tsconfig.json`, and `plugins/trace/.claude-plugin/` holds only `plugin.json`. Nothing in git history ever added `types/`, and `.gitignore` does not cover it, so it most likely existed only in the working copy where #10 (the band) was built. Without the base config there is no `jsx`, no `claude-code` / `claude-code/testing` module declarations, no `Shaped`, and no `noEmit`.

Side effect: because `noEmit` comes from the missing base, the failing run writes `plugins/trace/hooks/band.js` and `plugins/trace/test/band.test.js` next to the sources, untracked.

The other checks pass: `typecheck`, `npm test` (91), `test:mod` (11, `claude plugin test` supplies its own `claude-code` modules), and `validate`. Found while verifying #24.

## Acceptance criteria

- `npm run typecheck:mod` passes on a clean checkout, with no files beyond `npm install` and what is committed.
- The run writes no `.js` files into `plugins/trace/`.
- How the mod's type declarations are obtained (committed, generated by a Claude Code command, or a package) is either self-evident from the repo or written in the Developing section of the README.
