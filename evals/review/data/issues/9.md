# Keep the issue in context: re-injection and the progress-comment nudge

## Parent

#3

## What to build

The issue becomes the record that survives compaction (ADR 0006), and progress gets written back to it.

- At session start, after compaction, on resume, and when each subagent starts:
  - inject the linked issue's title, acceptance criteria and latest progress comment;
  - inject the list of related docs the agent must read. Reading them is still enforced by the hard block in the forced-reads ticket; this is orientation, not enforcement.
- The Stop hook blocks stopping **once** when commits were pushed since the issue's last comment. It asks for a progress comment: progress, decisions, verification results.

## Acceptance criteria

- [ ] After `/compact` in a live session, the issue essentials and the docs list are back in context
- [ ] Stopping after a push with no new issue comment is blocked exactly once, then allowed
- [ ] Nothing is injected in a repository that has not opted in
