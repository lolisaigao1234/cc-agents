# trace skill: point at skills the model can run, match ADR 0007's reads, and cap review rounds

A review of `plugins/trace/skills/trace/SKILL.md` (does any step want a tailored agent? no, a general-purpose one or none suffices) turned up places where the skill, and the hook messages that echo it, steer the model wrong.

1. **Skills the model cannot invoke.** The Track row names `to-tickets` and `to-spec`, the Implement row `implement`. All three set `disable-model-invocation: true`, so `Skill('to-tickets')` fails. The refusals at `trace.mjs:211` and `:218` and the band's Implement reason at `status.mjs:87` name them too.
2. **The Read row contradicts ADR 0007.** "the ADRs the change touches" leaves the choice to the model, which ADR 0007 rejected. The row leaves out the linked issue with its comments and the `docs/` files it links, and does not say the reads are per agent and lost on compaction. Its done-when is a self-assessment, not what the hooks check.
3. **Review order disagrees.** SKILL.md says review, then `pr`; the band's reason at `status.mjs:115` says open the PR, then review.
4. **`code-review` is ambiguous.** A built-in `code-review` skill exists beside `mattpocock-skills:code-review`. SKILL.md and `status.mjs:115` should name Matt's skill fully, with its fixed point (the branch's base) and with `GLOSSARY.md` and the active ADRs among its standards.
5. **No cap on review rounds.** An agent author fixes every finding, so review and fix can loop. Per [Solving code review at Anthropic](https://claude.dev/blog/solving-code-review-at-anthropic/): after three rounds, step back and reconsider the approach; re-review only the new diff after the first round; fix the class of bug, not the one line; answer every finding with a fix or a reason.

Out of scope: Review's done-when stays "a PR whose body says `Closes #<n>`" (ADR 0006); the band's gates do not change.

## Acceptance criteria

- [ ] SKILL.md names only skills the model can invoke for its own steps; `/to-tickets`, `/to-spec` and `/implement` appear as the human's to run, with what the model does instead.
- [ ] The Read row lists the related docs as ADR 0007 defines them, says each agent reads them in full itself and again after a compaction, and its done-when is the hooks' test.
- [ ] SKILL.md and the band's Review reason give the same order, and name `mattpocock-skills:code-review` in full.
- [ ] SKILL.md caps review-and-fix at three rounds, with diff-only re-review, class-of-bug fixes and every finding answered.
- [ ] The refusals and band reasons that name `to-tickets` or `implement` point at what the model can do.
- [ ] `npm test` passes.
