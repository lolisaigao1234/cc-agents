# Trace commit and PR gates: #n in commits, Closes #n in PRs

## Parent

#3

## What to build

Commits and PRs carry the link back to the issue (ADR 0006).

- `git commit` from Bash is refused when its message does not reference the branch's issue (`#<n>`).
- `gh pr create` is refused when its body does not contain `Closes #<n>` (or `Fixes` / `Resolves`) for that issue.
- Both deny messages name the linked issue and the exact text to add.

## Acceptance criteria

- [ ] Tests cover `-m` messages, multiple `-m` flags, `-F` / `--body-file`, heredoc bodies, and amend
- [ ] When the message or body cannot be determined from the command, the gate refuses with a reason; it never allows the commit or PR silently
- [ ] Live: both gates refuse without the reference and pass with it, in the main session and in a subagent
