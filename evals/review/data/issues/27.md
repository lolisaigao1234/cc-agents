# README: Quick start pastes both /plugin commands into one prompt

The Quick start puts `/plugin marketplace add lolisaigao1234/cc-agents` and `/plugin install trace@cc-agents` in one code block. Copying the block and pasting it into Claude Code sends both lines to the first prompt, and the marketplace dialog rejects it:

> 'lolisaigao1234/cc-agents /plugin install trace@cc-agents' is not a valid GitHub owner/repo shorthand.

Make the documented install route work on copy-paste: one command where Claude Code supports it (`/plugin install trace --marketplace …`, 2.1.275+; the shell flag needs 2.1.292+), and the two-step form split into separate blocks for older versions.
