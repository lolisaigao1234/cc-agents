# Delete the review engine and rename the plugin to trace

## Parent

#3

## What to build

Make the change easy: remove everything the decisions in #3 replace with existing skills, and rename the plugin to `trace`.

- Tag `quality-loop-v0.1.0` on the last commit that has the old code, and push the tag.
- Delete the review engine and everything that only serves it: the `review`, `improve`, `debug`, `full-send` and `tune-reviewer` skills, the four agents, the round step files, the CLI and its library modules, the eval runner, the old mod, and their tests.
- Keep only the destructive-git guard: its shell parser and destructive-command rules, and their table-driven tests. It is wired as the plugin's only hook.
- Rename the plugin to `trace` 0.2.0. It declares a dependency on `mattpocock-skills@claude-plugins-official`, and the marketplace allows that cross-marketplace dependency.
- Rewrite the root and plugin READMEs for the new purpose. Your preference for compacting at about 300k tokens becomes a README note pointing at Claude Code's own `autoCompactWindow` setting.

## Acceptance criteria

- [ ] The tag `quality-loop-v0.1.0` exists on origin and points at the last commit with the old code
- [ ] `npm run check` passes (typecheck, tests, plugin validation)
- [ ] `claude plugin validate` accepts the renamed plugin and the marketplace, dependency included
- [ ] In a live session with the plugin loaded, the guard refuses `git reset --hard` and `git push --force`
- [ ] No remaining file references the quality loop, except archived docs and the git tag
