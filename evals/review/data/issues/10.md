## Parent

#3

## What to build

You can see the trace at a glance, and what you see is what the hooks enforce.

- A mod band above the prompt shows:
  - the issue;
  - the pipeline step reached (read · track · branch · implement · review · update · close);
  - whether the related docs are read;
  - the PR and its CI state.
- `/trace` prints the detail: unread docs, the last issue comment, and the PR's checks.
- The band reads the same Trace state the hooks use, with no separate state.

## Acceptance criteria

- [ ] `claude plugin test` covers the band's states and `/trace`
- [ ] Live: the band moves as each step completes on a real issue
- [ ] The band yields (draws nothing) in a repository that has not opted in
